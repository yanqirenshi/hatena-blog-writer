# CLASSES.md 更新スキル

## 目的

`src/classes.el` の `defclass` 定義と `CLASSES.md` の内容を同期させる。

## 手順

1. `src/classes.el` を読み込み、全ての `defclass` 定義を把握する
2. 各クラスの `cl-defmethod` も把握する
3. 現在の `CLASSES.md` を読み込む
4. 差分を特定し、`CLASSES.md` を更新する

## CLASSES.md の記述フォーマット

以下のフォーマットに厳密に従うこと。

### ファイル全体の構造

```markdown
# CLASSES

hatena-blog-writer で定義されている EIEIO クラスの一覧です。

定義ファイル: `src/classes.el`

## クラス一覧

| クラス名 | 説明 |
|----------|------|
| `クラス名` | 説明 |

---

## クラス名

クラスの説明。

### スロット

| スロット | initarg | 型 | 初期値 | アクセサ | 説明 |
|----------|---------|------|--------|----------|------|
| `スロット名` | `:initarg` | `型` | 初期値 | `アクセサ名` | 説明 |

### コンストラクタ

コンストラクタの使用例をコードブロックで記述。

### メソッド

#### メソッド名

シグネチャ、説明、使用例。

### 型述語

型述語の使用例。

### 永続化

永続化に関する情報（保存先、形式、互換性）。
```

### 各クラスのセクションに含める項目

1. **クラスの説明** — 1行の概要
2. **スロット** — テーブル形式。全スロットを列挙
3. **コンストラクタ** — elisp コードブロックで使用例
4. **メソッド** — `cl-defmethod` で定義されたメソッドごとに、シグネチャ・説明・使用例
5. **型述語** — `クラス名-p` の使用例
6. **永続化** — 保存先・形式・互換性情報（該当する場合のみ）

### hbw-entry 固有の追加セクション

hbw-entry には以下の追加セクションを含める：

- **API レスポンスとの対応** — スロットと AtomPub XML 要素の対応テーブル

## 注意事項

- 日本語で記述する
- コード例は実際に動作するものにする
- `defclass` の `:documentation` に書かれた説明をベースにする
- スロットの型は `defclass` の `:type` をそのまま記述する。ただし `(or null string)` は `string or nil` と表記する
- 初期値が無いスロットは `―` と記述する
- クラス一覧テーブルは全クラスを含める
- クラスの順序は `src/classes.el` での定義順に従う
